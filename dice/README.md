# WONDER of WANDERER 判定補助ツール

TRPG『WONDER of WANDERER』のココフォリア用チャパレ式作成と、判定ログの成功度再計算を行うブラウザーツールです。

## 使い方

`index.html` をブラウザーで直接開いてください。サーバー、npm、外部API、外部フォントは不要です。

- 「① チャパレ式を作る」で能力値・得意分野・補正を入力し、生成式をコピーします。
- 「② ココフォリ結果を再計算」に判定ログを貼り付け、大成功・大失敗・相殺・ファンブルを再計算します。
- 解析後は出目の選択・変更、判定値 +1、超成功を反映し、確定結果をコピーできます。
- 画面右上の「通常 / ダーク / シンプル」で表示モードを切り替えられます。シンプルは装飾を抑えたグレースケール表示で、選択は次回起動時に復元されます。

## 判定ログの取り扱い

- 複数の判定が貼られた場合は、最後の `WW12` 判定を解析します。
- 式のダイス数と出目数が違うログ、D12の範囲外の出目は誤計算防止のため拒否します。
- 補正後の目標値が0以下または13以上でも、ログの値を保って計算します。

## ファイル

```text

```

## 回帰テスト（任意）

ツールの利用にNode.jsは不要です。開発時の回帰確認のみ、Node.jsがある環境で次を実行できます。

```powershell
node .\tests\run-tests.js
```

テストは外部パッケージを使いません。
